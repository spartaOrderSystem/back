# Sparta Order System

### 주문 관리 플랫폼
- 배달의 민족의 주문 방식을 기반으로 AI를 접목
- 기존에 가게 주인은 상품 설명 작성에 시간이 소요되었고, 고객은 상품 정보가 부족하여 구매 결정에 어려움을 겪었음
  AI를 사용하여 상품 설명을 생성함으로써 기존 방식의 비효율성을 해결
